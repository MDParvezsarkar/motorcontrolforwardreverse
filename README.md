# motorcontrolforwardreverse

Forward-Reverse Motor Control – PLC + HMI (with AUTO mode)


⚡ Forward-Reverse Motor Control | PLC + HMI + AUTO Mode

I’ve developed an interactive industrial automation simulation demonstrating how a three-phase induction motor can operate in both forward and reverse directions using PLC logic, push buttons, and an HMI touch panel.

🏭 Key Features:

✅ Forward and Reverse Motor Control  
✅ PLC-Based Control Logic  
✅ HMI Touch Panel Operation  
✅ Manual and Automatic Modes  
✅ Contactor Interlocking (KM1 & KM2)  
✅ 2-Second Reversal Dead Time  
✅ Three-Phase Power Circuit Visualization  
✅ Limit Switch-Based Conveyor Control  
✅ Animated Motor Speed and Direction  
✅ Real-World Factory Conveyor Application  

🔧 How does it work?

In forward mode, the PLC activates the forward contactor (KM1). In reverse mode, the reverse contactor (KM2) swaps two phases to change the motor’s direction.

An interlocking mechanism and a 2-second dead time help prevent both contactors from operating simultaneously during direction changes.

In AUTO mode, the conveyor moves forward and reverse between two limit switches, demonstrating a basic automated material-handling application.

This simulation is designed for learning and demonstration. Real installations require properly engineered electrical protection, safety interlocks, and commissioning tests.
